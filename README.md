# Почта Деда Мороза

Казуальная merge-2 игра для Яндекс Игр: соединяем игрушки, сладости и тёплые вещи, отвечаем на детские письма и строим терем Деда Мороза.

- `prototype/` — браузерный прототип доски (HTML/JS, открывается двойным кликом).
- `unity/` — проект Unity 6000.6 (тот же редактор, что у «Замка из сундуков»).

План на первую версию: 3 цепочки по 7 предметов, 2 генератора, 12 писем с ответами, терем по слоям, только rewarded-реклама. Отправка на модерацию до 5 декабря.
