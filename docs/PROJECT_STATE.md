Первые три истории появляются сразу; остальные по мере открытия подходящих производств/уровней. Повторная отправка сохраняет автора, просьбу и персональный ответ. - По восемь уровней запчастей и подарков у каждой мастерской. На поле сливаются запчасти и собираются подарки; сборка кнопкой рецепта по-прежнему оставляет подарок на полке конкретного письма. Можно собрать частично письмо из двух подарков. Готовый комплект отправляется отдельно.
- Три непрерывных обычных заказа. Новые учитывают доступные мастерские, постепенно увеличивают уровень подарков. Повторные и найденные письма идут отдельным дополнительным списком. Во время ожидания ответа продолжается работа.
- Посылка в пути 20 секунд, затем нужно открыть извещение и нажать получение награды/повторного заказа. Сохранённый результат 70/20/10. Подарок не получает сердечко при отправке. Повторный подарок собирается заново по исходному рецепту, повторная доставка успешна и даёт одно сердечко. Повреждение закрывает отправку без сердечка.
- К каждой первой посылке можно заранее прикрепить найденную бирку: гарантированная доставка. Повторной бирка не требуется. Бирка расходуется один раз.
- Поле 7×9. Большая часть (39 клеток) под снегом. Расчистка только по четырём соседям от открытых рабочих клеток, стоимость 1/2/5 сердечек. Дальний лёд нельзя открыть прямым нажатием без пути.
- Четыре фиксированные части каждого нового проекта находятся B4, F4, D6, D9; последняя — под льдом в нижней строке. Найденные части заполняют проект. Нужны явные «Собрать мастерскую» и «Перейти», а не только четыре находки.
- Под остальным снегом: мешочки энергии (8), термосы (16), ножницы, бирки, украшения, открытки с историями, найденное письмо. Нет производственных запчастей или готовых подарков. Некоторые клетки только расширяют стол. Всё вне merge-поля.
- Мешочки хранятся в панели находок; при пополнении выше предела не теряются — остаток остаётся в мешочке. Ножницы делят уровень N на две N−1 при наличии свободной клетки. Украшения видны в полосе комнаты, открытки читаются в альбоме; одна открытка даёт небольшой сохранённый мешочек энергии.
- Снежинки: максимум/старт 30, производство стоит 1, восстановление +1 за 30 секунд и офлайн. Полный стол ничего не тратит. Слияние, сборка, отправка и возврат без энергии; возврат не компенсирует ранее потраченную энергию.
- Явный режим «Быстрый тест ×10» ускоряет только ожидание: энергия за 3 секунды и ответы за 2 секунды. Переключение сохраняет уже прошедшую долю ожидания, режим сохраняется между запусками. Цены/вероятности не меняются. Это инструмент теста, не рекламная награда.
- Для упаковочной станции принято временное тестовое улучшение: повреждение 10% → 5%, потери остаются 20%; успешность первой отправки становится 75%. Пользователь одобрял направление, точное снижение выбрано для демонстрации и подлежит обсуждению. Транспорт/сортировщик дальше пока не реализованы.
- Между мастерскими сохраняются три обычных заказа, дополнительные и повторные заказы, упакованные подарки, посылки, сердечки, энергия, инструменты, украшения, открытки. Запчасти со стола убираются, новая доска подготовлена заново.

Отмена отправки восстанавливает состояние генератора случайных чисел: повтор той же отправки даёт прежний результат. Валидатор не допускает двойное успешное сердечко одной истории доставки.

## Визуальная концепция, которую сейчас обсуждаем

Главный экран внутри мастерской: большое поле на рабочем столе, над ним письма на прищепках. По краям холодное окно, пустая полка, нетопленая печь, дверь со снеговиком-почтальоном. Один тёплый светильник.
Комната меняется по мере восстановления: печь загорается, полки заполняются, появляются украшения. Фасад терема показывает общий прогресс.
Сгенерированный экран — направление для обсуждения. Цифры, кнопки и предметы на нём не задают баланс. В реализации нужны отдельные UI-элементы и квадратные клетки без перспективного искажения.

## Предложения ассистента, ещё не утверждённый объём работ

- Сначала цельный фрагмент на 10–15 минут: знакомство → три сценарных письма → заметное улучшение комнаты → кухня → первый ответ с рисунком.
- Первые заказы и открытия сделать вручную (в v7 фиксированы первые сюжетные письма), случайные подключать позже при необходимости.
- Дать игроку отдельное действие строительства за звёзды вместо автоматического строительства.
- Проверить, нужны ли 10 уровней; исходный урезанный план содержит 7.
- Сделать письма и детские рисунки основной эмоциональной наградой; несколько возвращающихся персонажей.
- Двигать события по прогрессу игрока, без обязательной привязки финала к 31 декабря.
- Начать с одной комнаты; другие помещения и внешнее развитие расширять после проверки игрового цикла.
